# Tourism Danau Toba

Repositori ini disiapkan untuk pengolahan data, pembangunan warehouse, pemodelan, pengembangan aplikasi, penulisan jurnal, dan pelaporan proyek pariwisata Danau Toba.

## Struktur Proyek

```text
.
├── README.md
├── app/                 # Area backend dan frontend
├── data/                # Data mentah, hasil olah, dan data referensi
├── docs/                # Dokumentasi, data dictionary, dan kualitas data
├── etl/                 # Skrip extract, transform, dan load
├── models/              # Model tersimpan dan model card
├── notebooks/           # EDA dan eksperimen model
├── paper/               # Naskah jurnal dan jurnal target
├── reports/
│   └── weekly/          # Laporan mingguan
└── warehouse/           # DDL skema bintang dan ERD
```

## Status Repositori

Struktur awal proyek telah dibuat dan masih menunggu implementasi. Direktori yang belum memiliki file konten dilindungi dengan file `.gitkeep` agar tetap dapat dilacak oleh Git.
